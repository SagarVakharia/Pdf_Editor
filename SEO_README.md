### ✅ Core Web Vitals Fixes

#### 1. PDF Worker — Local File (LCP improvement)
**File:** `frontend/src/components/editor/PDFViewer.tsx`

```diff
- pdfjs.GlobalWorkerOptions.workerSrc = `https://unpkg.com/pdfjs-dist@${pdfjs.version}/build/pdf.worker.min.mjs`;
+ pdfjs.GlobalWorkerOptions.workerSrc = '/pdf.worker.min.mjs';
```
The 1MB PDF worker was already in `/public/` but being fetched from `unpkg.com` on every load.  
Now served from Vercel's CDN edge — faster, cached, no external dependency.

#### 2. Google Fonts — Render-Blocking Fix (FCP improvement)
**File:** `frontend/src/app/layout.tsx`

```diff
- <link href="https://fonts.googleapis.com/css2?family=Dancing+Script..." rel="stylesheet" />
+ const dancingScript = Dancing_Script({ subsets: ['latin'], display: 'swap', variable: '--font-dancing-script' });
```
Next.js `next/font/google` automatically subsets fonts, self-hosts them on Vercel, and uses `font-display: swap` — eliminates render-blocking requests.

#### 3. Image + Performance Config
**File:** `frontend/next.config.ts`
- AVIF/WebP image format optimization (~30-50% smaller images)
- 1-year cache header on `pdf.worker.min.mjs`
- Security headers: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`

## 3. Manual Steps You Must Do

> These cannot be done in code — they require external accounts and configuration.

---

### Step A — Set Up Google Analytics (GA4)

**What it does:** Tracks real user visits, bounce rate, top pages, and traffic sources.

1. Go to [analytics.google.com](https://analytics.google.com)
2. Click **"Start measuring"** → create an account
3. Create a **Property** → choose **Web** → enter `pdf-editor-f1av.vercel.app`
4. Choose **Google Analytics 4** → complete setup
5. Copy your **Measurement ID** (looks like `G-XXXXXXXXXX`)
6. Go to your **Vercel dashboard** → open the `Pdf_Editor` project
7. Click **Settings** → **Environment Variables**
8. Click **Add New** and set:
   - **Name:** `NEXT_PUBLIC_GA_ID`
   - **Value:** `G-XXXXXXXXXX` *(paste your real ID)*
   - **Environments:** Production ✅, Preview ✅, Development ✅
9. Click **Save** → go to **Deployments** → **Redeploy** the latest deployment

✅ After redeployment, visit your site and check Analytics → Realtime to confirm it's working.

---

### Step B — Set Up Google Search Console (GSC)

**What it does:** Tells Google about your site, shows which keywords you rank for, and where to find your sitemap.

#### B1. Add Your Property
1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Click **"Add property"** → choose **URL prefix**
3. Enter: `https://pdf-editor-f1av.vercel.app`
4. Click **Continue**

#### B2. Get Your Verification Code
5. Choose **"HTML tag"** verification method
6. Copy the `content="..."` value from the meta tag shown — it looks like:  
   `abc123XYZ789...` (a long alphanumeric string)

#### B3. Add the Code to Your Codebase
7. Open `frontend/src/app/layout.tsx`
8. Find this line (around line 68):
   ```ts
   verification: {
     google: 'YOUR_GSC_VERIFICATION_CODE',
   },
   ```
9. Replace `YOUR_GSC_VERIFICATION_CODE` with your actual code:
   ```ts
   verification: {
     google: 'abc123XYZ789...',
   },
   ```
10. Save, commit, and push to GitHub → Vercel will auto-redeploy
11. Back in Search Console → click **Verify** → it should say ✅ Verified

#### B4. Submit Your Sitemap
12. In Search Console left sidebar → click **Sitemaps**
13. Enter `sitemap.xml` in the input box
14. Click **Submit**
15. Status should turn green showing your pages are indexed

### Step D — Update the Aggregate Rating (When You Have Real Reviews)

**What it does:** Shows star ratings in Google search results.

Currently in `frontend/src/components/JsonLd.tsx` there's a placeholder:
```json
"aggregateRating": {
  "ratingValue": "4.8",
  "ratingCount": "127"
}
```

When you collect real reviews (e.g., from a feedback form, Product Hunt, or a review widget):
1. Open `frontend/src/components/JsonLd.tsx`
2. Update `ratingValue` and `ratingCount` with real numbers
3. Commit and push

> ⚠️ Do NOT keep fake/placeholder ratings long-term — Google can penalize for misleading structured data.

---

### Step E — Update Domain if You Get a Custom Domain

If you ever move from `pdf-editor-f1av.vercel.app` to a custom domain (e.g., `pdfmaster.io`):

Update these 3 places:

1. **`frontend/src/app/layout.tsx`** line ~47:
   ```ts
   metadataBase: new URL('https://your-new-domain.com'),
   ```

2. **`frontend/src/app/sitemap.ts`** line ~3:
   ```ts
   const BASE_URL = 'https://your-new-domain.com';
   ```

3. **`frontend/src/app/robots.ts`** last line of the return object:
   ```ts
   sitemap: 'https://your-new-domain.com/sitemap.xml',
   host: 'https://your-new-domain.com',
   ```

Also update the `url` fields in the OpenGraph sections of each blog page if you want them to be precise (they'll still work without it, as `metadataBase` handles resolution).

## 4. Future Maintenance

### Adding a New Blog Post
1. Create a new folder: `frontend/src/app/blog/your-post-slug/`
2. Create `page.tsx` inside it — copy any existing blog post as a template
3. Update the post `metadata`, content, and JSON-LD `articleSchema` call
4. Add the new URL to `frontend/src/app/sitemap.ts`
5. Add a card for it in `frontend/src/app/blog/page.tsx`
6. Commit, push, and submit the updated sitemap in Google Search Console
